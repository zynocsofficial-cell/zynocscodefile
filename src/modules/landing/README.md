# Zynocs Marketing & Public Website (`zynocs.com`)

## Target Audience
- Public Visitors
- Prospective Clients
- Search Engine Crawlers (SEO)

## Primary Functionality
- Company portfolio & case studies
- Enterprise IT services showcase
- Leadership & core company values
- Careers & job openings
- Lead generation & consultation contact form

## Directory Structure
```
components/
├── Hero.tsx          # Dynamic hero section with tech ticker
├── Services.tsx      # Core services (Cloud, AI, Architecture)
├── Portfolio.tsx     # Enterprise case studies
├── Insights.tsx      # Tech thought leadership & articles
├── Testimonials.tsx  # Client reviews & trust signals
├── Stats.tsx         # Enterprise statistics & uptime proofs
├── Leadership.tsx    # Executive profiles (CEO & Chairperson)
├── Careers.tsx       # Benefits, culture & open roles
└── Contact.tsx       # Consultation request form
```
