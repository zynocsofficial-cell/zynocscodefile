# Zynocs Sponsors & Advertisers Dashboard (`sponsors.zynocs.com`)

## Target Audience
- External Clients: Advertisers, Sponsor Brands, Media Agencies

## Primary Functionality
- Real-time campaign performance reporting (Impressions, Clicks, CTR, Conversions)
- Ad creative uploads & asset validation
- Ad spend receipts, billing statements, and budget pacing controls

## Architecture Notes
- External client-facing authenticated portal.
- Read-heavy analytics powered by aggregated metrics APIs.
