# Zynocs Work Workspace (`work.zynocs.com`)

## Target Audience
- Internal Staff Only: Engineers, Project Managers, Supervisors, Executives & Admins

## Primary Functionality
- Dual-track project management:
  - In-house product engineering
  - Client custom software delivery
- Sprints, Kanban task boards, code reviews, and developer timesheets
- Internal system performance monitors & error telemetry

## Architecture Notes
- Reserved for internal team access only.
- Authentication uses Zynocs SSO (`*.zynocs.com`) with strict Role-Based Access Control (RBAC).
