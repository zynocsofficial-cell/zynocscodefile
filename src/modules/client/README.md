# Zynocs Client Software Portal (`client.zynocs.com`)

## Target Audience
- External Clients: Custom Software & Enterprise IT Clients

## Primary Functionality
- Project delivery roadmap & sprint milestones
- Staging and preview deployment links
- Contract, SOW, and architecture document downloads
- Invoice payment tracking & receipts
- Direct client bug reporting & feedback ticketing

## Architecture Notes
- Reserved for authenticated enterprise client stakeholders.
- Multi-tenant data isolation ensures clients only access their assigned contracts and deliverables.
